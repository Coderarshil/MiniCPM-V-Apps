# MiniCPM-V Android — English Localization

An Android-focused English localization and UI/UX refinement of the [OpenBMB MiniCPM-V Apps](https://github.com/OpenBMB/MiniCPM-V-Apps) project.

## What this repository contains

This repository provides the **Android source code only** for an English-localized version of MiniCPM-V Apps.

### My contributions

- English localization of the Android app
- UI/UX refinements for a cleaner, softer visual experience
- Visual adjustments inspired by the design language of Google Pixel
- Minor usability improvements while keeping the original app's functionality and purpose

These changes are intended to make the Android app more approachable for English-speaking users.

## Original project
